# Dotfiles

Personal desktop configuration for Hyprland, Waybar, Ghostty, and Wlogout.

## Contents

- `.config/hypr/hyprland.conf`
- `.config/waybar/config`
- `.config/waybar/style.css`
- `.config/ghostty/config.ghostty`
- `.config/wlogout/layout`
- `.config/wlogout/style.css`

The repository mirrors paths relative to the home directory. Copy selected
files into `~/.config/` to apply them on another machine.

The Hyprland configuration expects a wallpaper at
`~/Pictures/Wallpapers/Cyberpunk.png`; the image is intentionally not stored in
this repository.
